About Tatenda Zhou

I am a Software & Systems Architect and SRE with 10+ years in enterprise software. These days I build open-source tools that review, test and measure the work of AI coding agents, and I teach engineering teams to hand real work to those agents.

What I work on

  • Tools for AI coding agents. Review gates, a second agent that tests mobile apps before a PR opens, quota meters and model pickers. All open source; the list is below.
  • Agent evaluation. I benchmarked Codex models on 50 SWE-bench Verified tasks and found agents reading outside their workspace in 14 of 304 runs. The report is openai/codex#53166.
  • Native mobile. iOS and Android apps built for the store: auth, payments, polish.
  • Reliability. Cloud infrastructure, CI/CD, monitoring and alerting. I own reliability, not just features.

Workshops for engineering teams

From chat to coding agent is a half-day or full-day workshop for teams of 5 to 20 developers. Each developer hands a real ticket from the team's backlog to a coding agent, then we set up the checks that stop bad work before it reaches main. Remote first, flat fee per team. Details are on the home page.

Podcasts and talks

I am open to podcast interviews and talks about AI coding agents: how to check their work, what they cost, and how to run several at once.

Open-source tools for coding agents

Each has a project page on this site and its source on GitHub.

  • coderabbit-failover: one CodeRabbit review budget shared across agents, with a local Claude Code backup review when CodeRabbit is rate-limited. Source.
  • CodeAndConfirm: a second agent tests iOS and Android changes on the simulator and emulator before the PR opens. Source.
  • T-mods: Claude Code mods, including one that refuses gh pr merge until CI is green and a real review exists. Source.
  • QuotaSignal: ChatGPT and Codex weekly quota in the macOS menu bar or Windows tray. Source.
  • Model Picker: model and effort suggestions for Codex and Claude Code. Source.
  • Mission Control: a project board built from git, PRs and Claude Code session logs. Source.
  • herdr-launcher: unofficial macOS Dock launcher for the herdr TUI. Source.

More projects
