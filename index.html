Why I check what agents do.

I benchmarked Codex models on 50 SWE-bench Verified tasks. In 14 of 304 runs, the agent searched or read files outside its workspace, and some runs found the upstream fix instead of working out the bug. I reported it with the raw logs and repro scripts in openai/codex#53166.

A passing test does not prove the agent did the work. The tools above, and the workshop below, are about checking that it did.

From chat to coding agent: a workshop for engineering teams.

A half-day or full-day workshop for teams of 5 to 20 developers. Each developer hands a real ticket from your backlog to a coding agent, then we set up the checks that stop bad work before it reaches main. I teach with the tools on this page, run live on your code.

  • Every developer hands at least one real ticket to an agent and reviews the result.
  • Your team writes down the checks an agent's change must pass.
  • One automatic gate goes into a real repo on the day.

Remote first. Half day (4 hours) or full day (7 hours). Flat fee per team.
